# Ready-to-paste prompt for Gemini CLI

Open `gemini` in the repo root, then paste this:

```
Протестируй саппорт-бота в Jira Service Desk по инструкции из GEMINI.md.
Загрузи сценарии из scenarios/test-scenarios.xlsx, открой тестовую беседу в браузере,
прогони каждый сценарий по очереди, и в конце собери отчёт reports/report-*.xlsx.
Если потребуется вход через корпоративный SSO — останови работу и попроси меня
залогиниться вручную в открытом окне браузера.
```

Or in English:

```
Test the Jira Service Desk support bot following GEMINI.md. Load the scenarios from
scenarios/test-scenarios.xlsx, open the test conversation in the browser, run each
scenario one by one, then produce the Excel report. If corporate SSO login is needed,
pause and ask me to log in manually in the opened browser window.
```
